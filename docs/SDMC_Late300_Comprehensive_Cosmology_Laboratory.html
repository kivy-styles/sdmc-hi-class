Sources, assumptions and interpretive boundaries

This browser edition uses manuscript structural reference quantities and the canonical late300 parameter coordinates. It is a reduced numerical reconstruction: a standalone HTML file does not execute the full covariant Horndeski / hi_class system or the observed likelihood pipelines.

  1. Manuscript B, §51, Table 12 — canonical late300 parameter sheet, including H₀, ωb, ωc, F-transition, D-transition, tracker and late-background amplitudes.
  2. Manuscript B, §§52, 59, 113–117 — observable test sheets, accepted-action replay, derivability and conditional Bayesian model selection.
  3. Manuscript A, Part V, §§8–11, eqs. (25)–(42) — reconstruction identities and two-lobe Hubble residual δH.
  4. Manuscript A, Part VIII, §§32–33, eqs. (136)–(144) — independent kinetic D and the exact No-Slip parameter relation.
  5. Manuscript B, Part I, §§24–25 — structural kinematics, lapse, mapper, causal crossing and numerical calibration anchors.
  6. Structural Radius / Jacobian Continuation VI, §§122–137, eqs. (413) onward — action-coordinate status, coupled force balance, kinetic and tracker tests, derived-bundle observables.
Changing any accepted coordinate creates a new, unvalidated member of the reconstruction family. Re-evaluating likelihoods, perturbative stability or full mature-future dynamics requires an external action-level numerical calculation; the HTML deliberately does not invent those results.

Internal mathematical consistency

Tests verify shared-state recomputation, flat closure, exact No-Slip identities, positivity of the independent kinetic family, chronological structural-radius consistency, action-branch background replay and the 100-state count. Numerical scope

The late300 finite-epoch covariant continuation, prethermal Planck dynamics and mature future are distinct levels of inference. The current source action has not uniquely selected the full future operator or every historical structural coordinate. An analytic browser model cannot close that physics gap.
